# Algorithm references

The online Jump Point Search implementation follows Harabor and Grastien's grid pruning work, including the no-corner-cutting variant described in *The JPS Pathfinding System* (SoCS 2012). The directional rules were also checked against the MIT-licensed PathFinding.js implementation by its contributors (https://github.com/qiao/PathFinding.js, JPFMoveDiagonallyIfNoObstacles.js, author imor). A copy of that project's MIT notice is included in `Documentation~/PathFinding-js-LICENSE.txt`.

The existing PriorityQueue.dll is from BlueRaja's High-Speed Priority Queue for C#. Existing attribution in README is preserved.
